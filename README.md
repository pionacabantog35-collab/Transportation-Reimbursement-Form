# Transportation Reimbursement Form

A web-based Transportation Reimbursement Form designed to simplify the process of submitting and managing employee transportation expense requests.

The application allows employees to enter their personal information, add transportation details, upload receipt attachments, provide a digital signature, and automatically calculate the total reimbursement amount. The form also includes input validation to ensure that required information and transportation entries are completed before submission.

## Features

* Employee information form
* Digital signature pad
* Receipt attachment upload
* Support for multiple image and PDF receipts
* Drag-and-drop file upload
* Dynamic transportation expense entries
* Add and remove transportation rows
* Automatic grand total calculation
* Input validation for required fields
* Success and error status messages
* Reset form functionality
* Responsive design for different screen sizes

## Transportation Details

Users can add multiple transportation expenses with the following information:

* Date
* Type of transportation
* Origin
* Destination
* Reason for travel
* Amount

The system automatically calculates and displays the grand total based on all entered transportation expenses.

## Built With

* HTML5
* CSS3
* JavaScript

## Purpose

This project was created to demonstrate a digital and paperless approach to handling transportation reimbursement requests. It focuses on creating an interactive form with dynamic data entry, file uploads, client-side validation, automatic calculations, and a responsive user interface.
